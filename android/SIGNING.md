# Постоянный ключ подписи Android-приложения

Android ставит обновление поверх старой версии, только если оба APK подписаны **одним и
тем же ключом**. Раньше каждая сборка в GitHub Actions подписывалась новым случайным
отладочным ключом, поэтому обновление падало с `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, а
удаление приложения стирало библиотеку на телефоне.

Теперь релиз подписывается постоянным ключом из секретов репозитория. Ключ нужно завести
один раз и **никогда не терять**: без него ни одно будущее обновление не встанет поверх
установленного приложения.

## 1. Создать ключ

Нужен `keytool` из JDK. Обычно его нет в PATH, поэтому команда ниже вызывает его по
полному пути (JDK 21 из `C:\Program Files\Java`; в Android Studio он лежит в
`<Android Studio>\jbr\bin\keytool.exe`). Команда в PowerShell, из любой папки **вне
репозитория**:

```powershell
& "C:\Program Files\Java\jdk-21.0.10\bin\keytool.exe" -genkeypair -v -keystore mymusic-release.jks -alias mymusic -keyalg RSA -keysize 4096 -validity 36500
```

Если такого пути нет, найдите keytool: `Get-ChildItem "C:\Program Files" -Recurse -Filter keytool.exe -ErrorAction SilentlyContinue`.

keytool спросит пароль (придумайте надёжный и сохраните его) и данные владельца
(имя достаточно, остальное можно пропустить). Пароль ключа — тот же, что у хранилища.

Файл `mymusic-release.jks` **не кладите в репозиторий**.

## 2. Добавить секреты в GitHub

Из папки с ключом (нужен [GitHub CLI](https://cli.github.com/), `gh auth login`):

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("$PWD\mymusic-release.jks")) | gh secret set ANDROID_KEYSTORE_B64 -R Tlordo/musicplayer
gh secret set ANDROID_KEYSTORE_PASSWORD -R Tlordo/musicplayer
gh secret set ANDROID_KEY_ALIAS -R Tlordo/musicplayer -b mymusic
```

Вторая команда спросит пароль — введите тот, что задали в keytool. Если пароль ключа
отличается от пароля хранилища, добавьте ещё `gh secret set ANDROID_KEY_PASSWORD`.

Проверить: `gh secret list -R Tlordo/musicplayer` — должны быть три имени.

Релиз (запуск `build` с версией или тег `v*`) без этих секретов теперь **не собирается**:
лучше упавшая сборка, чем APK, который снова не встанет поверх. Простая сборка без версии
только предупреждает и подписывается отладочным ключом.

## 3. Сделать резервную копию

Сохраните `mymusic-release.jks` **и пароль** минимум в двух местах вне компьютера:
менеджер паролей (как вложение), зашифрованный облачный диск, флешка. Секрет в GitHub
прочитать обратно нельзя — если файл пропадёт, ключ потерян навсегда, и всем придётся
ещё раз удалять приложение.

## 4. Локальная сборка с этим ключом (по желанию)

Без настроек `gradlew assembleRelease` подписывает отладочным ключом, как раньше. Чтобы
подписать постоянным, добавьте в `%USERPROFILE%\.gradle\gradle.properties` (не в репозиторий):

```properties
MK_KEYSTORE_FILE=D:/keys/mymusic-release.jks
MK_KEYSTORE_PASSWORD=...
MK_KEY_ALIAS=mymusic
```

Те же имена работают и как переменные окружения; вместо файла можно передать
`MK_KEYSTORE_B64`.

## 5. Последнее удаление при переходе на постоянный ключ

Уже установленные версии (2.4.1 и раньше) подписаны случайными ключами, поэтому первую
версию с постоянным ключом поверх них поставить нельзя — **один раз придётся удалить
приложение**, и библиотека на телефоне сотрётся. Все следующие обновления встанут поверх.

Перед удалением сохраните музыку:

1. **Альбомы.** В приложении: «Библиотека» → «Альбомы» → альбом → кнопка «Скачать альбом
   архивом .zip» (стрелка вниз в шапке альбома). Получится
   `.zip` с музыкой, обложками и данными треков; на Android он попадает в «Загрузки».
   Так сделайте для каждого альбома.
2. **Треки вне альбомов.** Полного экспорта всей библиотеки в приложении нет — архивы
   собираются только по альбомам. Треки, которых нет ни в одном альбоме, сначала добавьте
   в новый альбом (например, «Всё») и выгрузите его.
3. **Свои темы.** «Настройки» → «Тема» → «Экспорт тем» (файл `my-music-themes.json`).

После установки новой версии: «Библиотека» → «Альбомы» → «Импорт» и выберите сохранённые
`.zip` (можно сразу несколько); темы — «Настройки» → «Импорт тем». Настройки плеера
(громкость, повтор, вид) не переносятся — их нужно выставить заново.

Файлы из «Загрузок» удаление приложения не трогает, но для надёжности скопируйте их на
компьютер до удаления.
