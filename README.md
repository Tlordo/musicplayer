# YouTube Audio Library Manager
YouTube Audio Library Manager — это удобный локальный сервер на Rust, созданный для автоматизации скачивания, систематизации и прослушивания аудиоконтента с YouTube. Проект позволяет превратить локальную папку в полноценную музыкальную медиатеку с метаданными и обложками.

## Особенности для пользователей

* Автономная работа: Все скачанные файлы хранятся на вашем устройстве.
* Умная структура: Метаданные (название, исполнитель, альбом, дата) автоматически извлекаются и сохраняются в SQL-базу данных.
* Восстановление: Если вы случайно удалите аудиофайл из папки, сервер автоматически попытается восстановить его при следующей попытке воспроизведения.
* Поддержка форматов: Работает через FFmpeg для конвертации аудио в высококачественный формат Opus.
* Простой API: Удобное управление библиотекой через HTTP-запросы.

## Инструкция по развертыванию

Сервер написан на Rust (axum + tokio + SQLite).

1. Установите Rust: https://rustup.rs
2. Установите [yt-dlp](https://github.com/yt-dlp/yt-dlp) и FFmpeg. Сервер ищет их так:
   * yt-dlp: `YTDLP_PATH` → `./yt-dlp(.exe)` → `./bin/yt-dlp(.exe)` → `PATH`;
   * ffmpeg: `FFMPEG_PATH` → `./ffmpeg/ffmpeg(.exe)` → `PATH`.
3. Аутентификация (необязательно): положите `cookies.txt` с куками браузера в корень проекта — тогда можно скачивать контент, доступный только авторизованным пользователям.
4. Запуск:
```
cargo run --release
```
После этого приложение будет доступно по адресу http://localhost:3000.

Переменные окружения: `PORT` (3000), `MUSIC_ROOT` (папка с `public/`, `Data/`, `database.db`; по умолчанию текущая), `COOKIES_PATH`, `MAX_DOWNLOADS` (одновременных загрузок, 2), `RUST_LOG` (уровень логов).

### Что улучшено по сравнению со старой Node-версией
* Перемотка работает: стриминг и обложки поддерживают HTTP Range, ETag и Last-Modified.
* Трек скачивается одним вызовом yt-dlp вместо двух.
* Настоящая SQLite (WAL, транзакции) вместо перезаписи всей базы на диск после каждого изменения; старый `database.db` открывается как есть.
* `video_id` проверяется — нельзя прочитать или удалить файлы вне `Data/` через `../`.
* Повторное восстановление одного трека не запускается дважды; число параллельных загрузок ограничено.
* Обложки скачиваются атомарно (без битых файлов при обрыве), предпочитается JPG вместо WebP.
* Удаление трека убирает и его `*_user_info.json`; удаление несуществующего трека отвечает 404.
* `cookies.txt` стал необязательным.

## Приложения

**Windows** — переносная папка с окном «Моя музыка.exe», встроенным сервером, yt-dlp и ffmpeg:
```
powershell -ExecutionPolicy Bypass -File tools\package-windows.ps1
```
(на машине без Visual Studio C++ — с `-Toolchain stable-x86_64-pc-windows-gnu`). Результат — `dist\MyMusic-Windows\` и `.zip`. Данные хранятся рядом с программой в `Data\`.

**Linux** — то же окно на WebKitGTK: `bash tools/package-linux.sh` (зависимости перечислены в начале скрипта), результат — `dist/MyMusic-Linux.tar.gz`; `install-menu-entry.sh` добавит программу в меню.

**Облачная сборка** — `.github/workflows/build.yml` собирает обе версии в GitHub Actions (Actions → build → Run workflow).

**iPhone и любой телефон** — открыть плеер с компьютера (адрес и QR-код: настройки → «Подключить телефон»), затем Safari → «Поделиться» → «На экран Домой»: появится иконка, плеер откроется во весь экран без адресной строки.

Без окна: `cargo run --release` (только сервер) или `cargo run --release --features desktop --bin mk60-desktop` (с окном).

## Интерфейс

Два дизайна, переключаются в настройках (шестерёнка) без остановки музыки:

* **Классика** — тёмный, обложки в списке, крупная обложка над размытым фоном из неё же, настоящая форма волны трека для перемотки и спектр.
* **Кассета** — библиотека как вкладыш МК-60, заполненный от руки; плеер — кассета из дымчатого пластика рядом с обложкой, перемотка пальцем по окошку, счётчик, флуоресцентный индикатор уровня.

**Поиск по названию** — в окне «Добавить трек» можно не искать ссылку, а написать «исполнитель — песня»: плеер найдёт трек на YouTube Music (или на YouTube) и покажет список, любой результат скачивается кнопкой «+».

**Альбомы** — свои подборки (создать, переименовать, добавить треки, «В альбом…» из меню трека) и альбомы, собранные автоматически по метаданным YouTube. Целый альбом или плейлист скачивается по ссылке: окно «Добавить трек» само предложит «весь альбом / плейлист», прогресс виден в углу.

**Перенос между устройствами** — кнопка «Скачать» на странице альбома отдаёт архив `.zip` (музыка, обложки, `manifest.json`); его же можно просто открыть проводником. На другом устройстве: «Альбомы → Импорт» — треки появятся в библиотеке без повторного скачивания, альбом восстановится.

**Рекомендации** — в классике вкладка рядом с библиотекой, в кассете «сторона Б» вкладыша: YouTube-микс по текущему треку, добавление одной кнопкой.

**Очередь** — зажмите трек в списке (на компьютере — правый клик): «Играть следующим», «В конец очереди», «В любимое», «В альбом», «О треке», «Скачать», «Удалить». Окно «Очередь» (меню ⋯ или клавиша Q) показывает, что прозвучит дальше: свою очередь можно переставлять и чистить. «Назад» возвращает к тому, что реально играло, а «вперемешку» не повторяет треки, пока не прозвучит весь список.

**Любимое и подборки** — сердце в плеере (клавиша F). В «Альбомах» плеер сам собирает подборки: «Любимое», «Чаще всего», «Давно не слушал», «Ещё не слушал». В библиотеке есть сортировка «чаще слушаю».

**Статистика** — меню ⋯ → «Статистика»: время прослушивания, число прослушиваний, график по дням и месяцам, топ треков и исполнителей за 7 дней / 30 дней / год / всё время. Трек засчитывается, если прозвучала половина его или 30 секунд. Хранится на сервере — общая для телефона и компьютера.

**Таймер сна** — меню ⋯ → «Таймер сна»: 10–90 минут или «до конца трека»; последние 20 секунд звук плавно затихает.

**Звук** — выравнивание громкости (сервер меряет громкость каждого трека по EBU R128, плеер приводит всё к −14 LUFS) и пятиполосный эквалайзер с пресетами; мягкий ограничитель не даёт хрипеть при подъёме.

Настройки: темы-пресеты для каждого дизайна и **свои темы** (редактор цветов с живым просмотром, экспорт/импорт в JSON), цвета из обложки, индикатор / текст песни / выкл, автопереход, отметки прослушанного. Хранятся в браузере устройства.

**Текст песни** — встроенный [musetext](public/musetext): кинетическая типографика по синхронизированному тексту из LRCLIB. Работает на месте индикатора или на весь экран (кнопка ⛶ или клавиша L); плеер сам передаёт ему трек, позицию, звук и обложку через `public/musetext/js/host-bridge.js` — код musetext не изменён, кроме одной строки подключения моста в его `index.html`.

Горячие клавиши: пробел — пауза, ←/→ — перемотка, ↑/↓ — громкость, N/P — следующий/предыдущий, S — вперемешку, R — повтор, M — звук, Q — очередь, F — в любимое, V — индикатор, L — текст песни, B — библиотека, / — поиск.

## API для взаимодействия
Вы можете управлять библиотекой через стандартные HTTP-методы:
```
POST /api/add — Добавить новый трек (передайте объект { "url": "..." } в теле запроса).
GET /api/search?q=… — Найти трек на YouTube по названию.
GET /api/library — Получить полный список треков с их метаданными.
GET /api/stream/:video_id — Потоковое воспроизведение аудио конкретного трека.
GET /api/thumbnail/:video_id — Получить обложку трека.
GET /api/peaks/:video_id — Форма волны трека (160 значений 0…1) и громкость `loudness` в LUFS; считается ffmpeg и кэшируется.
POST /api/track/:video_id/play { "seconds" } — Трек прослушан (в историю и счётчик прослушиваний).
POST /api/track/:video_id/like { "liked": true|false } — Избранное. В /api/library у треков есть plays, last_played, liked, liked_at.
GET /api/stats?days=30&tz=180 — Статистика: plays, seconds, tracks, top_tracks, top_artists, recent, days (по дням; tz — смещение пояса в минутах).
GET/POST /api/albums, PATCH/DELETE /api/albums/:id — Свои альбомы ({ "name", "tracks": [video_id…] }).
POST /api/albums/:id/tracks, DELETE /api/albums/:id/tracks/:video_id — Добавить/убрать трек.
GET /api/albums/:id/export, GET /api/export?name=&ids=a,b — Архив альбома .zip.
POST /api/import — Импорт архива (тело запроса — сам .zip).
POST /api/add-playlist { "url" } — Скачать альбом/плейлист в новый альбом (фоновая задача); GET /api/jobs — прогресс.
GET /api/recommendations?seed=:video_id — Рекомендации: YouTube-микс по треку (без seed — по трём последним добавленным), без того, что уже в библиотеке. `&fresh=1` — не брать из кэша.
DELETE /api/track/:video_id — Полное удаление трека из базы и файловой системы.
```
Хранение данных
```
/Data/Music — аудиофайлы в формате .opus.
/Data/Info — метаданные в формате .json и обложки в .jpg.
database.db — SQLite база данных для управления всей медиатекой.
```
