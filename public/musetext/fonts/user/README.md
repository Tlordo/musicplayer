# Свои шрифты

Сюда кладутся гарнитуры, которые нельзя положить в репозиторий.
Имя файла должно совпадать — оно прописано в `core/css/fonts.css`:

    BBHBartle.woff2   (или .woff, .ttf, .otf)
    Druk.woff2

Приложение при запуске пробует загрузить каждую из них. Если файла нет,
пресет молча берёт запасной шрифт, а в списке шрифтов рядом с названием
появляется пометка «нет файла».

Остальные пять гарнитур уже лежат в `core/fonts/` — они под лицензией
SIL Open Font License, все с кириллицей.
